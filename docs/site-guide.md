# Arturas Real Estate — Build Guide

Сайт целиком построен в системе **«Golden Hour»**. Предыдущая версия
(hubtown-style: палитра night/offwhite/royal, Onest + JetBrains Mono, HUD-рамка,
кастомный курсор, прелоадер, звук, три фоновые WebGL-сцены) удалена целиком —
двух дизайнов в коде не осталось. Данные (объекты, гиды, локали) не менялись.

## Routes

| URL | File | What |
|---|---|---|
| `/{lang}` | `app/[lang]/page.tsx` | **Главная.** Видео-герой, манифест, цифры, объекты, основатель |
| `/{lang}/about` | `.../about/page.tsx` | Портрет, манифест, паспорт данных, цифры, процесс |
| `/{lang}/projects` | `.../projects/page.tsx` | Сетка объектов |
| `/{lang}/projects/{slug}` | `.../projects/[slug]/page.tsx` | Кадр-герой, цифры, галерея, планировки, паспорт |
| `/{lang}/guides` | `.../guides/page.tsx` | Карточки статей-гидов |
| `/{lang}/guides/{slug}` | `.../guides/[slug]/page.tsx` | Статья: содержание, разделы, FAQ на `<details>` |
| `/{lang}/contact` | `.../contact/page.tsx` | Каналы + форма → `/api/telegram-lead` |
| `/{lang}/map` | `.../map/page.tsx` | Интерактивная 3D-карта Пхукета |
| `/{lang}/map/{slug}` | `.../map/[slug]/page.tsx` | Карта с открытым оверлеем проекта (deep-link) |

`{lang}` ∈ `en, ru, uk, de, th`. Оболочка (шапка, меню, футер) живёт в
`app/[lang]/layout.tsx`.

Главная снова самостоятельная страница: раньше `/{lang}` редиректил на
`/about`, потому что отдельной главной в прошлом дизайне не было. Редирект снят.

Навигация: **Projects** открывает 3D-карту, полный список — `/projects`.
`/map/{slug}` закрыт от индексации, canonical ведёт на карточку объекта.

## Видео-герой главной

`public/hero/` — `hero-1920.mp4` (7.0 МБ), `hero-1280.mp4` (3.5 МБ),
`hero-poster.jpg` (176 КБ). Исходник — 4K-таймлапс 3852×2152, 14 с, 72.6 МБ.

**Про бесшовность цикла.** Исходник идёт «день → ночь»: первый и последний
кадры различаются полностью, поэтому обычный `loop` давал бы рывок «ночь →
день». Кроссфейд тоже не годился — в кадре есть наезд камеры, растворение
двоило бы картинку. Файл пересобран в **палиндром**: прямой ход (кадры 0…336)
плюс обратный (335…1), крайние кадры не дублируются. Последний кадр
физически соседствует с первым — шва нет, а обратный ход читается как
естественный рассвет. Длительность ровно 28.00 с, 672 кадра при 24 fps.

Замер стыка (средняя разница по пикселю, 0–255): **стык 1.86** против **45.09**
у обычной склейки «ночь → день»; соседние кадры внутри ролика — 0.64. То есть
стык неотличим от обычного межкадрового движения.

Аудиодорожки в файлах нет намеренно: ресинк звука на границе цикла и есть та
самая «дёрганость» у большинства фоновых видео. `moov` вынесен в начало
(faststart) — видео начинает играть, не дожидаясь полной загрузки.

Пересобирается через `AVFoundation` (Swift) — ffmpeg и Homebrew проекту не
нужны; скрипты разовые и в репозитории не хранятся.

**Скрим — только под текстом.** Первая версия гасила кадр тремя слоями
(низ + клин слева на 0.8 + верх), суммарно ~0.87 в зоне текста: от ролика
доходило 13%, закат превращался в бурую кашу. Ради этого кадра всё и
делалось — так нельзя.

Замеры по полосам высоты показали, что кадр яркий почти везде (есть участки,
выжженные до 255,255,255), и светлому тексту для 4.5:1 нужно ≈0.61. Отсюда
устройство: боковой клин убран совсем; нижний градиент многоступенчатый и
**выше 72% от низа полностью прозрачен**, поэтому верхняя треть кадра не
тронута; под шапкой отдельная узкая полоса 144px.

Следствия, которые нельзя нарушать:
- **Весь текст героя — полной яркости.** `text-bone/70` на этом ролике даёт
  3.25:1. Иерархию держат кегль и воздух, а не прозрачность.
- **Золото в герое не работает**: даже при 0.75 затемнения оно даёт 3.99:1.
  Метки первого экрана — `text-bone`; золото живёт ниже сгиба, на сплошном фоне.
- **Метки не ставить в верх кадра**: там голое небо (1.3:1). Они вынесены на
  нижнюю кромку, где опора уже есть.
- Шапка, пока прозрачна, переключает текст на `text-bone`; приглушённый тон
  включается только вместе со сплошной подложкой при прокрутке.

Проверено по всей длине ролика: 16 из 16 текстовых элементов героя проходят
AA, худший 6.20:1.

`components/HeroVideo.tsx` сам выбирает источник по ширине экрана (атрибут
`media` у `<source>` внутри `<video>` браузеры игнорируют), гасит видео при
`prefers-reduced-motion` и `Save-Data`, снимает с декодирования за кадром через
IntersectionObserver. Постер отдаётся с `fetchPriority="high"` и служит
LCP-элементом.

## Design tokens (`tailwind.config.ts`)

- **Цвета** (контраст указан к фону `ink`):
  `ink #0B0C0A` (не чистый чёрный — на OLED он смазывается при прокрутке),
  `ink-soft #14160F`, `ink-raised #1C1F17`,
  `bone #F0EBE3` (16.5:1), `bone-dim #9A968D` (6.65:1),
  `bone-faint #827E76` (4.85:1 — нижняя граница AA, для подсказок и
  плейсхолдеров; альфа-затемнение вроде `bone-dim/50` давало 2.5:1 и не
  читалось). **4.85:1 — это только к `ink`.** На `ink-raised` тот же тон даёт
  **4.13:1** и AA уже не проходит, а поверх фотографии он зависит от кадра:
  на светлом небе исчезает совсем. Правило: `bone-faint` живёт на `ink` и
  больше нигде — на приподнятых подложках и над картинкой берётся `gold`
  (8.34:1) или `bone`.
  `gold #CBA35C` (8.34:1, работает и текстом, и фоном кнопки),
  `sage #8FA37A`, `danger #E5806B` (7.12:1).
- **Шрифты**: `Poiret One` (волосяной ар-деко) + `Inter` (текст) +
  `IBM Plex Mono` (метки) — все три с полной кириллицей.
  `Noto Serif Thai` / `Noto Sans Thai` подключены **без preload**: браузер
  возьмёт их, только встретив тайский текст.
  Playfair Display убран сознательно: это самый шаблонный «люкс», он не
  отличал сайт ни от одного конкурента. Кандидаты отбирались по реальным
  пробам кириллицей — Instrument Serif, Gloock, Italiana и Young Serif
  отпали, у них нет кириллических глифов вовсе.
  **Poiret One ставится только от 24px.** Начертание одно (Regular), и это
  дисциплина, а не ограничение: заголовок нельзя сделать громче весом —
  только размером и воздухом. На мелком кегле штрих истончается до серой
  дымки, поэтому общего правила `font-display` на `h1..h4` нет, класс
  проставляется точечно. Обратная сторона точечного класса — про него забывают:
  «Reputation, measured in numbers» и «Work with us» набирались Inter'ом среди
  Poiret-заголовков того же и меньшего кегля, причём CTA (52px) был крупнее
  соседей на Poiret (48px). Оба исправлены. Проверять глазами бесполезно —
  разница видна только рядом; надёжнее пройтись по `h1,h2` и сравнить
  `getComputedStyle(h).fontFamily`. Кегли `title` (min 24px) и `section`
  (min 30px) порог 24px держат на всех ширинах, `lead` и мельче — нет.
- **Кегли** на `clamp()`: `eyebrow / micro / body / lead / title / section /
  display`. Числовой шкалы `text-9…text-320` больше нет.
- Единая кривая `ease-smooth`, длительности `micro/base/slow` (200/320/560 мс).
- Радиусы только у элементов управления (`rounded-control`, пилюли кнопок);
  контент — прямые углы.

**Зерно.** `body::after` — фрактальный шум в data-URI поверх всей страницы
(`opacity .035`, `pointer-events: none`). Ровная заливка `#0B0C0A` на большом
экране читается как цифровая пустота и выдаёт полосы (banding) на градиентах
скрима; шум их разбивает и даёт бумажную фактуру. Слой обязан оставаться
`pointer-events: none`, иначе съедает все клики.

**Осторожно с модификаторами прозрачности.** Tailwind генерирует только кратные
пяти (`/95`, `/80`). `bg-ink/97` молча не создаётся — класс в разметке есть,
правила в CSS нет (так у мобильного меню пропадала подложка). Нужно другое
значение — писать `bg-ink/[0.97]`.

## Появление блоков

- Первый экран — `components/HeroReveal.tsx`: чистый CSS, без клиентского JS.
  Состояние покоя в разметке «видимо», анимация лишь проигрывается к нему
  (`fill-mode: both`). Заголовок первого экрана — LCP-элемент, прятать его до
  выполнения JS нельзя.
- Ниже сгиба — `components/Reveal.tsx`: IntersectionObserver + CSS-анимация,
  наблюдатель отключается после первого срабатывания.
- Стартовая прозрачность задаётся классом `.js .reveal-init`, а класс `js`
  вешает инлайн-скрипт в `layout.tsx` до первой отрисовки. Без JS правило не
  применяется — контент ниже сгиба остаётся видимым, а не прячется навсегда.
- `Odometer` — счётчик, а не барабан из десяти цифр под маской. Барабан
  зависел от метрик шрифта: ар-деко рисует цифры окружностями выше
  em-квадрата, соседи лезли в окно маски и число разваливалось на дуги.
  Счётчик от метрик не зависит. Стартует он с **настоящего** значения и
  обнуляется только в момент запуска анимации — иначе при отключённом JS
  или не сработавшем наблюдателе на странице навсегда осталось бы «0+».

## Карточка объекта

Сетка `/projects` и блок объектов на главной набраны одинаково: кадр 4:5, под
ним волосяная линия, дальше строка «номер — название — локация · тип» и стрелка.
Номер — `marker tabular text-gold` в подписи, **не поверх кадра**. Раньше на
`/projects` он лежал `absolute left-4 top-4` в `text-bone-faint`, а скрим у
карточки поднимается снизу и вверху прозрачен: над светлым небом (04, 06)
цифра пропадала полностью, а на запасной подложке `ink-raised` давала 4.13:1.
Это тот же случай, что и в герое («метки не ставить в верх кадра»): опору либо
рисуют, либо метку уносят туда, где фон сплошной. Здесь выбран второй путь —
фотография остаётся нетронутой, и обе сетки читаются как одна система.

## Имя основателя

`siteConfig.founder` — каноническая латиница «Arturas» (для JSON-LD и авторства
гидов). Видимое имя берётся из `founderName(lang)` в `lib/i18n/meta.ts`:
кириллица для `ru`/`uk`, латиница для `en`/`de`/`th`. Раньше на все пять локалей
шла одна кириллическая строка, и под портретом на `/en` стояло «АРТУРАС» —
прямо под латинским логотипом «Arturas» в шапке; та же строка уходила в `alt`
портрета. Новый язык — дописать строку в `founderNames`, иначе TypeScript
не соберётся (`Record<Locale, string>`).

## Предзагрузка маршрутов

`lib/prefetch.ts` — `linkPrefetch(href)`. Все `<Link>` в шапке, футере,
мобильном меню и в `Button` спрашивают её.

Карта — единственная тяжёлая страница: three.js + R3F дают **413 кБ** First
Load против **112 кБ** у остальных. Ссылка на неё («Projects») есть на каждой
странице, а Next в проде предзагружает `<Link>`, попавшие в кадр, — и бандл
карты уезжал посетителю всегда. Замер до/после на главной: **424 → 284 кБ**
JS (17 → 13 запросов), карта свои 425 кБ грузит как раньше.

`prefetch={false}` снимает только предзагрузку «по видимости»: на hover и
touchstart Next всё равно подтянет маршрут заранее, поэтому переход на карту
остаётся мгновенным. Появится ещё одна тяжёлая страница — добавить её в
регулярку, а не разбрасывать `prefetch` по разметке.

## Component map (`components/`)

- `dict.ts` — строки оболочки и страниц, 5 локалей.
- `Header.tsx` + `MenuOverlay.tsx` — шапка (прозрачная над видео, при прокрутке
  набирает подложку) и полноэкранное мобильное меню с ловушкой фокуса,
  Escape и блокировкой прокрутки фона.
- `Footer.tsx` — CTA, навигация, соцканалы. На карте не рендерится.
- `Button.tsx` — primary (золото) / secondary (обводка) / ghost, ≥44px.
- `HeroVideo.tsx` — фон-герой главной, см. выше.
- `HeroReveal.tsx`, `Reveal.tsx`, `Odometer.tsx` — появление и цифры.
- `LeadForm.tsx` — форма → Telegram-бот. У ошибок значок + текст, не только
  цвет; поля объявляют `autocomplete` и `inputmode`. `FieldError` несёт
  `role="alert"`: без него провал валидации был виден только глазами —
  `aria-invalid` уже стоял, но озвучивался лишь когда фокус приходил на поле.
  «Telegram / WhatsApp» — одно сообщение на два поля, поэтому у `Field` есть
  проп `describedBy`: оба поля ссылаются на общий `#contact-error`. Раньше они
  получали `aria-invalid` вообще без `aria-describedby`, и скринридер объявлял
  поле неверным, не сказав почему. `company` — honeypot, метки у него нет
  намеренно.
- `LangSwitch.tsx`, `CookieConsent.tsx`, `Analytics.tsx`.
- `map/` — `phuketGeo.ts` (районы и пины), `MapScene`, `MapExperience`.
  Единственное место, где ещё используется GSAP. Мелкие подписи карты —
  гротеск в верхнем регистре: антиква на 9–11px нечитаема, а минускульные
  цифры ломают счётчик «00 проектов».

## Версии React и R3F — не откатывать

Next 15 отдаёт клиентским компонентам **свой** React 19. С React 18 в
`package.json` любая сцена на `@react-three/fiber` падает с
`Cannot read properties of undefined (reading 'ReactCurrentOwner')`.

Рабочая связка: `react`/`react-dom` 19, `@react-three/fiber` 9,
`@react-three/drei` 10. `@react-three/postprocessing` прибит к 3.0.4 без
каретки: с 3.0.5 он требует `three >= 0.182`, а проект на `three` 0.169.

`lenis` и `framer-motion` из зависимостей удалены — прокрутка нативная,
анимации на CSS.

## Локальная разработка

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прогон всех 190 статических страниц
```

## Деплой

`git push` в `main` — Vercel собирает и публикует автоматически. Переменные
окружения (`NEXT_PUBLIC_SITE_URL`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`,
`NEXT_PUBLIC_GTM_ID`, `NEXT_PUBLIC_GA_ID`) задаются в Project → Settings →
Environment Variables, в репозитории их нет.

## Known non-issues

- В превью-харнессе R3F-канвас может замереть на 300×150 после программного
  ресайза; событие `resize` чинит. Реальные браузеры считают размер при
  загрузке, `MapExperience` шлёт resize при монтировании.
- Reduced-motion: видео-герой останавливается и показывает постер, карта
  замораживает воду и пульсацию и рисует по требованию.
