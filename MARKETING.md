# Запуск Google Ads — гайд для Arturas Real Estate

Документ для запуска платного трафика на сайт. Цель — поток заявок на покупку
недвижимости на Пхукете. Главный канал конверсии — **WhatsApp** и форма заявки.

---

## Что уже сделано в коде (готово к работе)

- **Домен через переменную** `NEXT_PUBLIC_SITE_URL` — метаданные, sitemap,
  robots и canonical подхватятся автоматически.
- **GA4 / Google Tag Manager** — подключаются переменными `NEXT_PUBLIC_GA_ID` /
  `NEXT_PUBLIC_GTM_ID`. Без них на сайте не грузится ничего лишнего.
- **Google Consent Mode v2** + **баннер согласия на cookie** (RU/UK/EN/DE/TH) —
  по умолчанию всё «denied», после «Принять» поднимается до «granted». Нужно для
  трафика из ЕС/Германии (GDPR).
- **Трекинг конверсий** (события `dataLayer` / `gtag`):
  - `generate_lead` — отправлена форма (`method: form`)
  - `contact_whatsapp` — клик по WhatsApp (navbar, плавающая кнопка, блок контактов)
  - `contact_telegram` — клик по Telegram
- **Захват источника трафика** (UTM, `gclid`, реферер, страница входа) — first-touch
  за сессию, прикрепляется к заявке и приходит агенту в Telegram. Видно, какая
  кампания/объявление дали лид.
- **WhatsApp с предзаполненным сообщением** везде; на страницах объектов в текст
  подставляется название проекта.
- **Плавающая кнопка WhatsApp** на всех страницах (главный «горячий» CTA).

## Что нужно сделать руками (вне кода)

### 1. Домен и хостинг

- [ ] Купить домен (например `arturasrealestate.com`).
- [ ] Привязать к Vercel (Project → Settings → Domains).
- [ ] Задать `NEXT_PUBLIC_SITE_URL=https://<домен>` в переменных Vercel → Redeploy.

### 2. Аналитика

- [ ] Создать **Google Tag Manager** контейнер → вставить ID в `NEXT_PUBLIC_GTM_ID`.
- [ ] Создать **GA4** ресурс. Подключить его внутри GTM (тег GA4 Configuration)
      ИЛИ задать `NEXT_PUBLIC_GA_ID` напрямую.
- [ ] В GA4 отметить события `generate_lead`, `contact_whatsapp`, `contact_telegram`
      как **ключевые события (конверсии)**.
- [ ] В GTM добавить триггер **Outbound click** по ссылкам, содержащим `wa.me` и
      `t.me` — чтобы ловить ВСЕ клики по WhatsApp/Telegram (в т.ч. со страниц
      объектов, где трекинг идёт через GTM, а не через код).
- [ ] Подключить **Google Search Console**, отправить sitemap: `<домен>/sitemap.xml`.

### 3. Google Ads

- [ ] Создать аккаунт **Google Ads** + привязать платёжную карту.
- [ ] Связать Google Ads ↔ GA4 (импорт конверсий) и Google Ads ↔ Search Console.
- [ ] Импортировать конверсии из GA4: `generate_lead` (основная), `contact_whatsapp`.
- [ ] Поставить **Google Ads tag** через GTM (для ремаркетинга и точных конверсий).
- [ ] Создать аудитории ремаркетинга (посетители 30/60/90 дней, смотревшие объект).

### 4. Профиль и доверие

- [ ] **Google Business Profile** агента — бесплатные звонки/заявки с карт.
- [ ] Реальная страница **Политики конфиденциальности** (ссылка в футере уже есть).

## Структура кампаний (рекомендация на старт)

Бюджет старта: **$25–30/день** (минимум для накопления данных). Распределение:

| Кампания | Тип | Доля | Когда включать |
|---|---|---|---|
| Search RU | Поиск | ~50% | сразу |
| Search EN | Поиск | ~20% | сразу |
| Search DE | Поиск | ~10% | если есть бюджет |
| Remarketing | GDN/YouTube | ~20% | через 1–2 недели |
| Performance Max | PMax | — | после 20–30 конверсий |

**Настройки Search-кампаний на старте:**
- Стратегия ставок: **Maximize Clicks** или **Manual CPC** (пока мало конверсий),
  затем **Maximize Conversions / tCPA**.
- **Отключить** Display Network и Search Partners (отдельные галочки).
- Языки: русский + английский. Гео: РФ, Казахстан, Беларусь, Германия, ОАЭ, UK,
  Израиль (выбрать по реальной аудитории; исключить страны без покупателей).
- Тип гео-таргетинга: **Presence** (кто физически в стране), не «интерес».

## Тексты объявлений (RSA)

**Заголовки** (минимум 10 на группу):
- Недвижимость на Пхукете под цель
- Доходность 9–11% годовых в $
- Подбор от инвестора · 15 лет опыта
- Прямые цены от застройщика
- Рассрочка от девелопера без %
- 100+ объектов на Пхукете
- Ответ в WhatsApp за 2 минуты
- Layan Verde · Gardens of Eden · Sun Hills
- Полное сопровождение сделки
- {KeyWord:Недвижимость на Пхукете}

**Описания:**
- Помогаю выбрать недвижимость на Пхукете под цель: жизнь, аренда 9–11%, рост капитала.
- Прямой контакт с агентом. WhatsApp / Telegram. Подбор объектов за 24 часа.

**Ассеты (расширения):**
- Sitelinks: «Объекты», «Сервис», «Об агенте», «Получить подборку»
- Callouts: «15+ лет опыта», «Сопровождение сделки», «Управление арендой», «Релокация»
- Structured snippets (Районы): Bang Tao, Layan, Nai Yang, Лагуна
- **Lead form extension** — форма прямо в выдаче
- **Call / WhatsApp** — кнопка связи

## Посадочные страницы

- Группы D (бренды) → **страницы объектов** `/<lang>/projects/<slug>` (уже готовы
  как лендинги, WhatsApp подставляет название проекта).
- Группы A/B/C → главная с якорем `/<lang>/#projects` или `/<lang>/#contact`.
- В URL объявлений добавлять UTM, например:
  `?utm_source=google&utm_medium=cpc&utm_campaign=ru_search&utm_term={keyword}` —
  они автоматически попадут в заявку из Telegram.

## Идеи для роста отклика (следующие шаги)

- **Ремаркетинг на Telegram-канал** `@arturas_invest` — «дозревание» долгих сделок.
- **Customer Match** — загрузить контакты прошлых покупателей для look-alike.

## KPI

Смотреть на **CPL (стоимость заявки)**, а не на CTR/CPC.
Ориентир для премиум-недвижимости Пхукета: WhatsApp-лид **$20–60**, форма **$40–120**.
Дальше воронка агента: заявка → встреча → показ → сделка.
